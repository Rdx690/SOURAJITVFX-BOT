## Environment variables
| Name | Purpose |
|------|---------|
| `GITHUB_TOKEN` | GitHub token used to store sessions (never commit it) |
| `GITHUB_REPO` | `username/repo` that stores sessions |
| `PAIR_URL` | Public URL of your deployed pair site (used by `.pair`) |
| `ADMIN_KEY` | Optional key for `/disconnect?key=` |
| `OWNER_NUMBER` | Comma separated owner numbers (default `916909950582`) |

## Run
```
npm install
npm start
```
Open `/` in the browser to get a pairing code (`pair.html`).
